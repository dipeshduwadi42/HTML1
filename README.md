# Amazon Clone Landing Page

A simple Amazon-inspired landing page built using **HTML5** and **CSS3**. This project demonstrates the use of semantic HTML, Flexbox layout, forms, responsive design basics, hover effects, and a structured webpage consisting of a header, registration form, and footer.

## 📸 Features

* Amazon-style header
* Sticky navigation bar
* Search bar with button
* Country/location display
* Navigation menu (Account, Orders, Cart)
* Registration form with:

  * Full Name
  * Email
  * Date of Birth
  * Country Selection
  * Gender Selection
  * Skills (HTML, CSS, JavaScript)
  * Skill Level Slider
* Hover animations
* Responsive form layout
* Footer with social media icons
* Font Awesome icons integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome 7
